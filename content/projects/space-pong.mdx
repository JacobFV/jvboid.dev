## Overview

Space Pong is a small Blender Game Engine project from Summer 2015. It takes the familiar back-and-forth rhythm of Pong and puts it inside a space-themed Blender scene, turning the `.blend` file itself into the playable artifact.

The video above is a demonstration of the original game running in Blender. It shows the core loop: two paddles, a moving ball, and local two-player controls designed so both players can sit at one keyboard. It can also be played solo by controlling both sides yourself.

## Controls

- Left player: `W`, `A`, `S`, `D`
- Right player: `I`, `J`, `K`, `L`

## Run It Yourself

The playable file is archived in the public [Space Pong GitHub repo](https://github.com/JacobFV/space-pong). Because this was built for the old Blender Game Engine, it should be opened with Blender 2.7x rather than a modern Blender release.

1. Download Blender 2.7x from the [official Blender release archive](https://download.blender.org/release/).
2. Download [`Space Pong.blend`](https://github.com/JacobFV/space-pong/raw/main/Space%20Pong.blend).
3. Open `Space Pong.blend` using Blender 2.7x.
4. Click start/run in Blender to launch the game.

Have fun playing against your friends, or against yourself.
